# The Stack I Actually Use

Everyone has opinions about tech stacks. Here's mine — stripped of hype, just what I actually reach for day to day.

## Frontend

**React** is my go-to for anything interactive. I've tried Vue and Angular, but React's ecosystem and component model clicked for me.

For styling I prefer **vanilla CSS** with custom properties. It keeps things predictable and performant — no class name gymnastics.

## Backend

**Node.js + Express** for APIs. Fast to set up, huge ecosystem, and JavaScript end-to-end is a nice mental model.

For more complex systems I reach for **Python + FastAPI** — the type hints and async support are excellent.

## Database

- **PostgreSQL** for anything relational
- **MongoDB** when the data structure is flexible or document-oriented
- **Redis** for caching and sessions

## Dev Tools I Can't Live Without

| Tool | Why |
|------|-----|
| VS Code | Fast, customisable, great extensions |
| Git + GitHub | Version control + collaboration |
| Postman | API testing made visual |
| Figma | Quick UI mockups |
| Vercel / Netlify | Deployment in seconds |

## What I'm Learning

Right now I'm getting deeper into:

- **TypeScript** — the type safety pays off at scale
- **Docker** — for consistent dev/prod environments
- **System design** — architecture matters more than syntax

## The Honest Take

There's no perfect stack. The best tools are the ones you can ship with confidently. Pick something, go deep, and don't chase every shiny new thing.

Master the fundamentals. The rest follows.
